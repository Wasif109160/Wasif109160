## ⚙️ Step 2: Enable GitHub Actions Permissions for Contribution Snake

To allow the snake action to push the generated SVG to your `output` branch automatically:

1. Go to your repository on GitHub:
   👉 **`https://github.com/Wasif109160/Wasif109160/settings/actions`**
2. Scroll down to **Workflow permissions**.
3. Select **"Read and write permissions"**.
4. Check the box **"Allow GitHub Actions to create and approve pull requests"**.
5. Click **Save**.

### Run the Snake Action for the First Time:
1. Go to the **Actions** tab: `https://github.com/Wasif109160/Wasif109160/actions`
2. Click on **"Generate Snake Animation"** on the left menu.
3. Click **"Run workflow"** ➔ **Run workflow**.
4. Within 30 seconds, a branch named `output` will be created with your snake animations!
